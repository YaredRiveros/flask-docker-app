# flask-docker-app

El contenido de este proyecto (aplicación Flask, Dockerfile, Docker Compose) se
encuentra en la rama [`feature/flask-docker-compose`](https://github.com/YaredRiveros/flask-docker-app/tree/feature/flask-docker-compose).

`main` se mantiene limpio como rama de integración, siguiendo un flujo tipo
GitFlow: el desarrollo ocurre en ramas `feature/*` y se integra a `main`
mediante pull requests.
